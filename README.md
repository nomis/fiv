# Fast Image Viewer
Created to learn ~~C++~~ Rust and to load and view large JPEG images very
quickly (by preloading previous/next images in the background).

## Dependencies (Debian/Ubuntu)
```
apt install \
	cmake \
	libatk1.0-dev \
	libcairo-dev \
	libgexiv2-dev \
	libgtk-3-dev \
	libheif-dev \
	libturbojpeg0-dev \
	nasm
```
